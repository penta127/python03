# py03

小規模なシステムやデータ処理の演習を通じて、Python での設計を学ぶステージです。

## どんなことをやるか

- `ft_command_quest.py`: コマンド処理やクエリの扱い
- `ft_score_analytics.py`: スコア集計と分析ロジック
- `ft_coordinate_system.py`: 座標データの計算と変換
- `ft_achievement_tracker.py`: 状態管理とトラッキング
- `ft_inventory_system.py`: アイテム管理やデータ構造の操作
- `ft_data_stream.py`: 連続データの受け渡しや処理の流れを扱う
- `ft_analytics_dashboard.py`: 分析結果の出力と要約

## 目的

- 複数のデータを扱う処理の組み立て方を学ぶ
- 小さなシステムを構築するための設計力を高める
- 実践的な問題を通じて Python の表現力を伸ばす

## 実行方法

1. `cd py03/exN`
2. `python3 ft_*.py`

`py03` は、より実践的なアプリケーション構造に近い演習です。

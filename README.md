# py03

このフォルダでは、小規模なシステムやデータ処理の流れを作る演習をします。
コマンド入力、集計、座標計算、進捗管理など、複数のデータを扱う処理を組み立てます。

## 何をする課題か

- `ex0/ft_command_quest.py`: コマンドの入力順に応じて処理を切り替える
- `ex1/ft_score_analytics.py`: 受験結果や点数を集計して傾向を見る
- `ex2/ft_coordinate_system.py`: 2次元上の座標を使って位置関係を計算する
- `ex3/ft_achievement_tracker.py`: 進捗や達成状況を記録して管理する
- `ex4/ft_inventory_system.py`: アイテムの所持数や状態を管理する
- `ex5/ft_data_stream.py`: 連続したデータを順に受け取って処理する
- `ex6/ft_analytics_dashboard.py`: 分析結果をわかりやすい形式で表示する

## ここで学ぶこと

- 複数のデータを扱う処理の組み立て方
- 小さなシステムを構築するための設計
- 実践的な問題を通じて Python の表現力を伸ばす

## 実行方法

1. `cd py03/exN`
2. `python3 ft_*.py`

`py03` は、より実践的なアプリケーション構造に近い演習です。
